Browser timing self-test

Browser timing is not rig timing. This page measures what a browser lets a page see: when the browser began each frame, how fine its clock is, whether the page is isolated, and when the page was hidden. It cannot see when the display showed a frame. A photodiode on a lab rig measures that; a browser never does. What a browser can and cannot claim.

The test draws a gray field with a bar that moves one step per frame, for the number of frames below. A skipped frame shows as a jump of the bar and as an interval near twice the period. Press a few keys during the run to measure how late the program sees a key after the browser stamped it.
