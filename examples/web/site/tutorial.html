Tilt discrimination: a keyboard reaction time

Browser timing is not rig timing. The times on this page are what the browser reports. The browser does not report when the display showed a frame, so the onsets are estimates and every reaction time includes an unknown delay. Use a lab rig for a timing claim. How the web backend works.

Instructions

Each trial shows a cross, then a striped patch. The stripes lean to the left or to the right.

Press F when the stripes lean left. Press J when they lean right. Answer as fast as you can without mistakes. A green ring means correct, red means wrong, gray means too slow.

There are 10 trials, about 30 seconds. Shift+Esc or the Stop button ends the run early.
