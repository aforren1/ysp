ysp web demos

ysp is a set of single-header, public-domain C libraries for psychophysics rigs. These pages run small experiments built from those headers, compiled to WebAssembly with Emscripten. Each one is the same C a lab rig runs, with the browser in place of the operating system's display path.

Browser timing is not rig timing. A browser does not report when the display showed a frame, gives no control over the display, and runs other work on the same thread. On these pages, timing is measured and reported, never controlled. Use a lab rig with a photodiode for a timing claim. What the web backend does.
  • Tilt discrimination: a fixation cross, a Gabor tilted left or right, a keyboard reaction time, 10 trials, the results and a CSV download.
  • Dot motion threshold: random dot motion, left or right, with a staircase on coherence; the threshold estimate at the end.
  • Stimulus gallery: gratings, Gabors, noise, dots, shapes, text and animation, eight pages of ysp/gfx.h.
  • Browser timing self-test: the measured refresh, a histogram of the intervals between frame callbacks, the clock's resolution, isolation and key latency.

Each page needs WebGL2 and a keyboard. The first visit can reload the page once: a service worker makes the site cross-origin isolated, which gives a finer clock. In a private window the service worker may be off, and the pages run without it.
